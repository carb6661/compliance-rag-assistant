# 威胁模型

| 资产/边界 | 风险 | 已实施控制 | 剩余限制 |
| --- | --- | --- | --- |
| 本地标准→解析器 | 超限、无效编码、错标题、跨级别污染 | 有界读取、UTF-8、标题栈、必填校验 | 无法确认语义或来源真实 |
| 配置→元数据 | 错别名、错误版本、别名重叠 | 精确配置、枚举、重叠拒绝、配置摘要 | 配置者仍需人工核验 |
| Markdown→后续RAG | 命令式文字或恶意链接 | 不执行、不抓取、元数据标unverified | 不提供语义注入检测；后续模型需独立边界 |
| CLI→文件系统 | 覆盖输入、路径越界、输出被替换 | 输入/配置冲突检查、符号链接拒绝、原子创建 | 非多用户隔离服务；输出父目录须可信 |
| API→服务器 | 任意文件读取、URL抓取、超大请求 | 只接收文本、不提供路径/URL接口、有界请求、Host限制 | 无鉴权/租户隔离/限流，仅回环原型 |
| 导出→公开仓库 | 标准全文/客户资料泄露 | 只提交原创样本，忽略private-docs/output | Git忽略不等于权限或脱敏 |
| 资料→SQLite | 旧块/向量残留、部分更新、丢失更新/旧草稿误删 | 严格解析后同事务替换/级联；0.3事务内来源ETag条件检查及generation防ABA | 不提供审批/自动合并/历史版本，多用户权限未实现；旧写者或直接SQL不受此合同保护 |
| 查询→候选 | 混版本/级别、先检索后过滤丢结果 | 必填范围，SQL过滤后再BM25/余弦/RRF | 范围不是身份授权，阈值不是答案置信度 |
| 检索材料/问题→LLM | 提示词注入、内容外传 | 系统规则与JSON资料分离、6000字符预算、双重显式许可 | 不是语义防火墙，服务商政策须人工审核 |
| 模型→答案 | 引用造假、超长/截断、工具调用、旧快照 | schema/ID/连续原文验证、响应64KiB、无执行、发布前revision复核 | 不证明事实支持/相关性，最终发送窗口存在 |
| 凭据→兼容服务 | 重定向/代理/客户端改URL泄漏 | Key仅server env、URL固定、禁重定向/trust_env、HTTPS、静态错误 | 管理员必须选择可信主机，未设置硬任务截止/成本配额 |
| 分析员→结论 | 把引用正确误认为合规 | 明确证据选摘、保留缺口及unverified | 仍需权威原文与人工测评 |

摘要用于绑定文件版本，不是签名或保管链。文档标题和正文都属于不可信数据；元数据的来源信任不因为提取成功自动提升。

API按文档只监听127.0.0.1；不要改为0.0.0.0直接开放。上线需另加鉴权/租户隔离、配额/任务截止时间/worker、日志保密与恢复。LangChain只用于Document；0.2额外在显式启用时实例化兼容HTTP客户端，未启用外部LangSmith追踪。本地trace只含状态/计数/耗时，最多1000条；原文和向量仍明文保存在私有SQLite。本项目不抵抗具有本机文件写权限的恶意主体。
