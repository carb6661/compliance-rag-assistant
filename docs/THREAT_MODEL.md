# 威胁模型

| 资产/边界 | 风险 | 已实施控制 | 剩余限制 |
| --- | --- | --- | --- |
| 本地标准→解析器 | 超限、无效编码、错标题、跨级别污染 | 有界读取、UTF-8、标题栈、必填校验 | 无法确认语义或来源真实 |
| 配置→元数据 | 错别名、错误版本、别名重叠 | 精确配置、枚举、重叠拒绝、配置摘要 | 配置者仍需人工核验 |
| Markdown→后续RAG | 命令式文字或恶意链接 | 不执行、不抓取、元数据标unverified | 不提供语义注入检测；后续模型需独立边界 |
| CLI→文件系统 | 覆盖输入、路径越界、输出被替换 | 输入/配置冲突检查、符号链接拒绝、原子创建 | 非多用户隔离服务；输出父目录须可信 |
| API→服务器 | 匿名读取/维护、任意文件读取、超限任务 | 默认锁定、随机令牌摘要/角色、正文前有界准入；0.5普通查询再做来源ACL | 无租户命名空间/段落权限；非公网/传输层DoS方案 |
| 导出→公开仓库 | 标准全文/客户资料泄露 | 只提交原创样本，忽略private-docs/output | Git忽略不等于权限或脱敏 |
| 资料→SQLite | 旧块/向量残留、部分更新、丢失更新/旧草稿误删 | 同事务替换/级联；来源ETag条件及generation防ABA；替换清空读ACL | 不提供审批工作流/自动合并/历史版本；旧服务、CLI或直接SQL可绕过HTTP控制 |
| 查询→候选 | 混版本/级别、先检索后过滤丢结果 | 必填范围，SQL过滤后再BM25/余弦/RRF | 范围不是身份授权，阈值不是答案置信度 |
| 身份→来源→候选/LLM | 同scope跨来源读取、未授权文本影响评分或外传 | schema3持久读ACL、ID+凭据绑定、SQL先过滤、评分/生成前后复核；独立授权ETag及内容重审 | 整文件粒度、维护者全库、检查后窗口仍在，不能撤回已外传材料 |
| 检索材料/问题→LLM | 提示词注入、内容外传 | 系统规则与JSON资料分离、6000字符预算、双重显式许可 | 不是语义防火墙，服务商政策须人工审核 |
| 模型→答案 | 引用造假、超长/截断、工具调用、旧快照 | schema/ID/连续原文验证、响应64KiB、无执行、发布前revision复核 | 不证明事实支持/相关性，最终发送窗口存在 |
| 凭据→兼容服务 | 重定向/代理/客户端改URL泄漏 | Key从server env取、私有管道到固定worker；固定URL/HTTPS/禁重定向代理，生成角色门禁 | 管理员须选可信主机，worker不是OS权限沙箱，远端任务/费用不受本地kill控制 |
| HTTP/线程→容量 | 连续提交、取消后后台工作 | 滚动频率及任务槽，HTTP/worker占用结束才归还；外部选摘默认45秒预算 | 计数重启清零，无跨实例额度；慢正文/BGE/SQLite未有全请求硬时限 |
| 父进程→provider worker | 阻塞管道、超时假释放、stdout协议污染 | 固定Python -I/无shell、最小环境、JSON包64KiB、独立读写、超时kill/wait；未确认回收保留容量 | OS启动不可处处中断；非CPU/内存/系统调用沙箱，无父进程崩溃/进程树恢复保证 |
| API令牌→身份 | 泄露、角色伪造、环境损坏降级 | 随机32字节、摘要比较、角色白名单、策略缺失锁定；新凭据不继承旧来源读ACL | 无令牌在线撤销/过期/IdP、不可篡改操作审计；同OS用户文件访问不受保护 |
| 分析员→结论 | 把引用正确误认为合规 | 明确证据选摘、保留缺口及unverified | 仍需权威原文与人工测评 |
| 目标响应→质量结论 | 空引用/操作故障计成功、伪造scope/出处、总分掩盖退化 | 0.7来源清单/原文摘要重放、逐项事实锚点、语义/操作拒答分离、完整case清单及比较 | 非通用语义蕴含、非独立人工gold；当前6题原文不充分仍未解决 |
| 资料/ACL事务→维护证据 | 修改成功但事件丢失、伪造操作者、删除级联擦除历史 | 0.8同事务记录、服务端actor、独立事件表、故障一起回滚 | 仅提交变更；无拒绝日志/签名/WORM，旧写者/本机管理员可绕过 |
| 私有维护历史→导出 | 读者越权、导出混入后续提交、无限分页/覆盖文件 | maintainer限定、库instance/序号上界、CLI默认100条/100页与字节预算、独占原子输出 | 元数据仍敏感；游标不认证历史，导出不解除满额写入阻塞，无正式归档清理 |
| gold/私有观测→目标/公开报告 | 参考答案进入提示词、原文/异常公开 | capture只传AskRequest，原始观测仅显式本地输出，公开评分报告无问题/正文/任意reason | 同OS恶意目标可读gold，指纹不认证执行身份；开发者须审阅目标声明与标注 |

摘要用于绑定文件版本，不是签名或保管链。文档标题和正文都属于不可信数据；元数据的来源信任不因为提取成功自动提升。

API只监听127.0.0.1、单worker，不能直接公网开放。静态角色/来源ACL/额度和生成预算不代替真实IdP、全请求资源隔离、日志保密与恢复。LangChain只用于Document，出站兼容HTTP仅显式启用，未启用LangSmith。query trace仅含状态/计数/耗时、最多1000条；0.8另有同事务维护事件，非防篡改审计。原文/向量/授权摘要及管理历史仍明文私有SQLite，不能抵抗本机写者。参见[任务边界](ACCESS_CONTROL.md)、[来源授权](SOURCE_AUTHORIZATION.md)、[生成worker](GENERATION_WORKERS.md)及[维护记录](MAINTENANCE_AUDIT.md)。
